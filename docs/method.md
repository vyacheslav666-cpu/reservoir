# Как устроен эксперимент

Задача: удержать перевёрнутый маятник на тележке, видя только положение
тележки и угол стержня. Для LQR-регулятора нужны ещё обе скорости, поэтому
линейный регулятор по одним `x` и `θ` с задачей не справляется. Резервуар
даёт линейному выходу память о прошлых наблюдениях, из которой скорости
восстанавливаются.

Всё описанное ниже относится к [cartpole_esn.py](../cartpole_esn.py), номера
шагов совпадают с разделами файла.

## 1. Физика

Классическая модель cart-pole (Barto, Sutton, Anderson, 1983).

| Параметр | Значение |
|---|---|
| Масса тележки | 1.0 кг |
| Масса стержня | 0.1 кг |
| Половина длины стержня `l` | 0.5 м |
| Шаг управления `dt` | 0.02 с (50 Гц) |
| Ограничение силы `F_max` | ±10 Н |
| Края рельса `x_lim` | ±2.4 м |
| Угол падения `th_lim` | ±0.7 рад (≈ 40°) |

Состояние `s = (x, ẋ, θ, θ̇)` интегрируется методом Рунге–Кутты 4-го порядка.
Эпизод заканчивается падением, если тележка вышла за край рельса или угол
превысил порог. Начальное состояние: `x ~ U(−1, 1)`, `θ ~ U(−0.2, 0.2)`,
скорости нулевые.

## 2. Учитель: LQR

Система линеаризуется в верхней точке центральными разностями, затем
дискретизуется рядом для `exp(A·dt)` и `∫exp(A·τ)dτ·B`. Коэффициенты
получаются 3000 итерациями дискретного уравнения Риккати с весами
`Q = diag(1, 0.1, 10, 0.1)`, `R = 0.1`:

```
K = [−2.83, −4.18, −39.6, −9.9]
u_teacher = clip(−K·s, −10, 10)
```

Учитель видит полное состояние, включая скорости.

## 3. Резервуар

### Наблюдения

Резервуар получает два числа: `x` и `θ` с гауссовым шумом датчиков
(σ = 0.002 м и 0.002 рад), нормированные на `(2.4, 0.2)`.

### Динамика

Leaky-integrator ESN:

```
r ← (1 − a)·r + a·tanh(W·r + W_in·o + b)
u = clip(W_out·[r, 1], −10, 10)
```

`a` — leak rate (`lr` в коде), `W_in ~ U(−1, 1)·in_scale`, `b ~ U(−0.2, 0.2)`.
Матрица `W` масштабируется так, чтобы её спектральный радиус был равен `ρ`
(`spectral_radius`).

### Матрица из коннектома

Каждый нейрон *C. elegans* — один нейрон резервуара (N = 300). Вес связи
`pre → post` строится из числа синапсов `n`:

- химический синапс: `W[post, pre] += log(1 + n)`, со знаком минус, если
  пресинаптический нейрон ГАМК-ергический (26 нейронов: DD, VD, RME, RIS,
  AVL, DVB);
- щелевой контакт: симметричный и возбуждающий, `log(1 + n) / 2` в обе
  стороны. Каждый контакт записан в CSV дважды, поэтому в сумме получается
  `log(1 + n)` на направление.

Логарифм сглаживает разброс: связь из 50 синапсов не в 50 раз сильнее связи
из одного. Получается 5084 ненулевых элементов матрицы.

### Вход только в сенсорные нейроны

При `input_to = "sensory"` строки `W_in` всех нейронов, кроме сенсорных,
обнуляются. Сенсорными считаются нейроны 37 классов (ASE, AWC, PLM и т. д.,
класс — первые три буквы имени), всего 84 из 300. Сигнал до остальных
нейронов доходит только через связи коннектома.

### Случайный резервуар для сравнения

При `reservoir = "random"`: `W ~ U(−1, 1)`, из которых оставлена доля
`sparsity` связей, затем то же масштабирование по `ρ`. Размер, входы и
смещения те же.

### Washout

Перед каждым эпизодом резервуар `washout` шагов получает начальное
наблюдение, чтобы забыть предыдущий эпизод и выйти на установившееся
состояние.

## 4. Прогон системы

Функция `run()` ведёт симуляцию заданное число шагов. На каждом шаге:

1. резервуар обновляется по новому наблюдению;
2. учитель считает свою силу по полному состоянию — она становится меткой;
3. применяется смесь `u = β·u_teacher + (1 − β)·u_esn`;
4. при `explore=True` к силе добавляется шум Орнштейна–Уленбека
   (`ou ← 0.8·ou + 0.8·ξ`, `u += 1.5·ou`), чтобы данные покрывали больше
   состояний;
5. при `kicks=True` с вероятностью 0.5 % за шаг стержень получает толчок
   `θ̇ += 0.8·ξ`;
6. после падения эпизод начинается заново, падение засчитывается.

## 5. Обучение

Обучается только `W_out`, ридж-регрессией по признакам `[r, 1]`:

```
W_out = (SᵀS + reg·I)⁻¹ SᵀY
```

1. **Имитация учителя.** 15 000 шагов (5 мин), управляет учитель (`β = 1`)
   с шумом и толчками.
2. **DAgger.** 10 000 шагов (3 мин 20 с), управляет смесь `β = 0.5`.
   Резервуар попадает в состояния, которых учитель сам не создаёт, а учитель
   их размечает. `W_out` пересчитывается по всем 25 000 примерам.

## 6. Тест

3000 шагов (60 с), управляет только резервуар (`β = 0`), без шума
исследования, со случайными толчками. Метрики:

- **число падений** за 60 с;
- **RMSE силы** резервуара относительно того, что сделал бы учитель в тех же
  состояниях.

Для сравнения обучается линейный регулятор по `[x, θ, 1]` без резервуара на
15 000 шагах учителя и тестируется 60 с — без толчков, то есть в более
лёгких условиях.

## Подбор гиперпараметров

[tune_esn.py](../tune_esn.py) подбирает параметры отдельно для коннектома и
для случайной сети с одинаковым бюджетом, используя те же `run()` и `ridge()`.

| Параметр | Диапазон | Режимы |
|---|---|---|
| `spectral_radius` | 0.7 – 1.1 | оба |
| `lr` | 0.2 – 1.0 | оба |
| `in_scale` | 0.5 – 1.5 | оба |
| `reg` | 1e-6 – 1e-2, логарифмически | оба |
| `sparsity` | 0.05 – 0.2 | только случайный |

Чтобы сравнение было честным:

- `W_in` и смещения общие для обоих режимов (генератор с сидом 0), режимы
  отличаются только матрицей `W`;
- случайная матрица одна на все trials (сид 1): от `sparsity` зависит только
  порог маски, так что сеть с `sparsity = 0.1` содержит все связи сети с 0.05;
- сэмплер TPE с одинаковым сидом для обоих режимов.

Оценка одного trial: полный цикл «обучение → DAgger → тест» на сидах 100 и 101,

```
score = среднее число падений + RMSE / F_max
```

Главное — не ронять маятник; RMSE меньше `F_max`, поэтому он только различает
trials с одинаковым числом падений. Лучший trial переоценивается на 10 новых
сидах (1000–1009), потому что на сидах подбора его результат завышен.

Параметр `washout` не подбирается и остаётся равным значению из
`cartpole_esn.py` (50 шагов).

## Чем отличается интерактивная версия

[cartpole_esn.html](../cartpole_esn.html) повторяет физику, учителя и
построение резервуара на JavaScript, но:

- выход обучается онлайн, на каждом шаге, рекурсивными наименьшими квадратами
  (λ = 1), а не одной ридж-регрессией;
- спектральный радиус оценивается степенными итерациями;
- параметры по умолчанию — лучшие найденные для коннектома (ρ = 0.91,
  a = 0.41, масштаб входа 0.52), washout 200 шагов;
- для случайного резервуара можно менять число нейронов;
- есть флажок «резервуар видит скорости» — для сравнения с полным состоянием.
