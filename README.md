# Резервуар-балансир

Эксперименты с резервуарными вычислениями (Echo State Network). Главный
эксперимент — перевёрнутый маятник на тележке, который держит резервуар,
построенный из нервной системы нематоды *C. elegans* (300 нейронов, связи из
реального коннектома).

Резервуар видит только положение тележки `x` и угол `θ`, без скоростей.
Скорости ему приходится «вычислять» самому из памяти о прошлых входах.
Обучается только линейный выходной слой: он имитирует учителя — LQR-регулятор,
которому известно полное состояние.

Итог коротко: резервуар держит маятник 60 с со случайными толчками почти без
падений, а тот же линейный выход без резервуара роняет его 8 раз за 60 с.
Коннектом червя и случайная сеть того же размера после равного подбора
гиперпараметров работают одинаково хорошо. Перемешанный коннектом (те же
веса на случайных местах) с теми же параметрами тоже не хуже, то есть
биологическая топология здесь роли не играет. Подробности в
[docs/results.md](docs/results.md).

## Установка

Нужен Python 3.10 или новее.

```bash
pip install -r requirements.txt
```

## Запуск

### Основной эксперимент

```bash
python cartpole_esn.py
```

Скрипт учит выходной слой (5 мин симуляции под управлением учителя, затем
3 мин 20 с DAgger), тестирует резервуар 60 с с толчками и открывает окно с
анимацией: тележка, активность 300 нейронов, угол и сила резервуара против
силы учителя. Работает несколько секунд.

Пример вывода:

```
LQR: K = [ -2.83  -4.18 -39.6   -9.9 ]
Резервуар: connectome, нейронов: 300, связей: 5084
Вход только в сенсорные нейроны: 84 из 300
Обучение (учитель): падений 0, RMSE силы 0.777 Н
DAgger: падений 1, всего 25000 примеров
Тест 60 с с толчками: падений 0
RMSE резервуар vs учитель: 0.724 Н
Без резервуара (только x и угол): падений за 60 с 8
```

Переключатели в начале шага 3 файла:

- `reservoir` — `"connectome"` (коннектом червя), `"random"` (случайная
  разреженная сеть того же размера) или один из двух контролей топологии:
  `"shuffled"` (те же веса коннектома на случайных местах) и `"rewired"`
  (рёбра перемешаны, но у каждого нейрона сохранены число входов и выходов);
- `input_to = "sensory"` или `"all"` — входные сигналы идут только в 84
  сенсорных нейрона или во все 300.

Там же заданы `spectral_radius`, `lr` (leak rate), `in_scale`, `reg` и
`washout`, а рядом — условия: шум датчиков `obs_noise`, толчки `kick_prob`,
`kick_every`, `kick_strength` и диапазон начального угла `th0_range`. Без графического окна скрипт можно прогнать так:
`MPLBACKEND=Agg python cartpole_esn.py`.

### Подбор гиперпараметров

```bash
python tune_esn.py --trials 200
python tune_esn.py --mode random --trials 200
python tune_esn.py --mode shuffled --trials 200
python tune_esn.py --final-only
```

Первая команда подбирает параметры для коннектома и случайной сети по
очереди, вторая и третья — только для одного режима. Два режима можно запустить параллельно в двух терминалах:
они пишут в одну базу, но в разные studies. Если базы ещё нет, сначала
создайте её (`python -c "import optuna; optuna.storages.RDBStorage('sqlite:///tune_esn.db')"`),
иначе оба процесса начнут создавать таблицы одновременно и второй упадёт
с `table studies already exists`. `--final-only` ничего не
подбирает, а переоценивает лучшие trials из базы на 10 новых сидах.
Прерванный подбор продолжается с того же места: база хранит готовые trials.

Подбор идёт в более тяжёлых условиях, чем `cartpole_esn.py`: старт с углом
20–35°, толчок каждые 1–2 с, шум датчиков 2 см и 0.02 рад. В обычных условиях
почти любые параметры дают 0 падений, и падения перестают различать
конфигурации. Условия задаются в начале `tune_esn.py`.

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `--mode` | `both` | `connectome`, `random`, `shuffled`, `rewired` или `both` (первые два) |
| `--trials` | 200 | Бюджет trials на каждый режим |
| `--seeds` | 3 | Прогонов на один trial |
| `--final-seeds` | 10 | Прогонов в финальной оценке |
| `--storage` | `sqlite:///tune_esn.db` | Где хранить результаты |
| `--jobs` | число ядер | Процессов, в которых параллельно идут сиды; `1` — всё в одном процессе |

Один прогон — полный цикл «обучение → DAgger → тест», 2–3 с на одном ядре.
Сиды одного trial и финальной оценки идут параллельно, каждый в своём
процессе; результат от этого не меняется — каждый прогон начинается со своего
`np.random.seed`. Скорость у всех четырёх резервуаров одна: матрица хранится
плотной, и число связей на время не влияет. BLAS ограничен одним потоком
(`OPENBLAS_NUM_THREADS=1`, задаётся в начале скриптов): для матрицы 300×300
многопоточность только мешает. До этого в первом подборе (2 прогона на trial,
сиды по очереди) 200 trials на режим заняли 40–50 минут, подбор контролей
(3 прогона на trial) — около 30.

### Сравнение на новых сидах

```bash
python compare_esn.py
```

Берёт лучшие trials всех четырёх режимов из `tune_esn.db` и прогоняет их на
50 новых сидах (2000–2049; `--seeds`, `--first-seed`). Для двух контролей
есть ещё вариант «plug-in»: параметры, подобранные для коннектома, и новая
перемешанная матрица на каждом сиде. Печатает медиану, среднее, IQR и долю
прогонов с 0 и 6+ падениями, затем сравнивает каждую конфигурацию с
коннектомом: тесты Уилкоксона (парный) и Манна–Уитни, бутстрап по сидам.
Рисует `falls_hist_50.png` (коннектом и случайная сеть) и
`falls_controls_50.png` (все конфигурации). Прогоны кешируются в
`compare_<режим>[_plugin]_50.json`: с готовыми файлами скрипт работает за
секунды. Без них сиды идут параллельно (`--jobs`, по умолчанию все ядра), и на
28 потоках 50 сидов одной конфигурации считаются за 7–12 с; по одному сиду
за раз было 10–30 минут на все конфигурации.

### Интерактивная версия

`cartpole_esn.html` — самодостаточная страница: физика, LQR, коннектом и
обучение переписаны на JavaScript, из сети грузятся только шрифты Google Fonts
(без интернета страница работает со стандартными шрифтами). Её можно открыть
прямо из файла или через локальный сервер:

```bash
python -m http.server 8765 --bind 127.0.0.1
```

и затем открыть <http://127.0.0.1:8765/cartpole_esn.html>.

Три режима:

1. **Учитель управляет** — LQR держит маятник с небольшим шумом, резервуар
   смотрит и учится. Выходной слой подстраивается каждый шаг рекурсивными
   наименьшими квадратами (RLS).
2. **Резервуар управляет** — обучение остановлено.
3. **Резервуар управляет и доучивается** — учитель только подсказывает
   правильную силу (DAgger).

По умолчанию управление переходит к резервуару после 90 с обучения. Клик по
сцене или клавиши ← → толкают маятник, пробел ставит на паузу. Параметры
резервуара (N, ρ, leak rate, масштаб входа, шум датчиков, washout) меняются
слайдерами; по умолчанию стоят лучшие найденные для коннектома.

Попробуйте после обучения поставить ρ = 0 и a = 1: резервуар теряет память,
скорости оценить не из чего, и маятник падает.

## Данные коннектома

Связи взяты из реконструкции Cook et al. (2019) в обработке проекта
OpenWorm/c302: 300 нейронов гермафродита, 3638 химических синапсов и 2168
записей щелевых контактов. Мышцы и другие клетки исключены. Формат CSV:

```
Source,Target,Weight,Type
I1L,I2L,10,chemical
```

`Weight` — число синапсов, `Type` — `chemical` или `electrical`. Как из этого
строится матрица резервуара, описано в [docs/method.md](docs/method.md#резервуар).

> Cook S. J. et al. Whole-animal connectomes of both *Caenorhabditis elegans*
> sexes. *Nature* 571, 63–71 (2019).
